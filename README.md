# Absürt Selamlaşma Algoritması

## Bu Repo Nedir?

Bu, insanlığın en büyük sorununu çözmek için yazılmış en ciddi, en akademik, en Nobel ödüllük projedir: **Nasıl selamlaşılır?**

Evet, duydunuz. Selamlaşmak. O kadar basit bir şey ki, yıllardır kimse doğru düzgün yapamamış. Bu algoritma, tamamen rastgele, tamamen absürt, tamamen gereksiz selamlar üretir. Ve GERÇEKTEN ÇALIŞIR.

### Neden Bu Kadar Önemli?

- Bilim insanları 40 yıldır bu sorunu çözemedi.
- Dünya barışı bu algoritmaya bağlıdır (belki).
- Eğer bu kodu çalıştırmazsanız, güneş batmayabilir. Risk almayın.

## Nasıl Kullanılır?

```bash
python selamlama.py
```

Sonra oturup izleyin. Algoritma size hayatın anlamını selam şeklinde verir.
